# Screen flow (MealKit module)

Title, menu, join, lobby (ready, a lobby choice, chat), loading, pause and results screens for [MealKit](https://github.com/MealKit-Engine/MealKit) games, over the engine's match service. Docs: [docs/index.md](docs/index.md).

> **Beta (v0.x).** MealKit is under active development: APIs and file formats may change between versions until v1.0, and projects are moved forward with the upgrade tool. Feedback and bug reports are welcome.

```
tools\module.ps1 add -Project <your project> screens
```
