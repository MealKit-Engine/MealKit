# Camera rigs (MealKit module)

Player camera controls for [MealKit](https://github.com/MealKit-Engine/MealKit) games: orbit and zoom over the engine's camera brain (third person), and a 2D side-view follow camera. Docs: [docs/index.md](docs/index.md).

> **Beta (v0.x).** MealKit is under active development: APIs and file formats may change between versions until v1.0, and projects are moved forward with the upgrade tool. Feedback and bug reports are welcome.

```
tools\module.ps1 add -Project <your project> camrig
```
